## Featured project
### [Hospital Appointment No-Show Prediction](https://github.com/Blessing-data/hospital-no-show-prediction)
A leakage-safe machine-learning pipeline that ranks advance bookings by no-show risk, so a clinic can direct scarce reminder calls where they matter most.
- On unseen patients, the model's top-ranked ~10% reached no-shows **1.48x** as efficiently as random selection.
- Patient-grouped split, test set used once, threshold fixed before testing.
- Two misleading patterns (including a Simpson's paradox in SMS reminders) caught and explained with the data.
- A fairness audit that led to a clear recommendation: use the model for supportive calls, **not** overbooking.
